Server & síť

Starý notebook jako home server, domácí síť pod kontrolou a soukromí, které se dá měřit

Všechno, co na tomhle webu najdeš — trackery, AI boti, tenhle web, zálohy, DNS pro celý byt — běží na jednom vysloužilém firemním notebooku v Dockeru. Bez otevřeného portu do internetu, s baterií jako záložním zdrojem a s cílem, aby cizí cloud viděl z mojí domácnosti co nejmíň. Tahle sekce je o tom, jak to stavím, co mě překvapilo a co bych dnes udělal jinak.

Základ, na kterém stojí všechny díly výše

Železo

  • Vysloužilý firemní notebook (i7, 32 GB)
  • Baterie = záložní zdroj
  • Kubuntu LTS, kabel 2,5 GbE
  • Home Assistant zvlášť na Raspberry Pi

Web ven

  • Docker Compose pro všechno
  • Caddy jako reverzní proxy
  • Cloudflare Tunnel — žádný otevřený port
  • Domácí IP nikde nevidět

Síť & přístup

  • AdGuard Home — DNS pro celý byt
  • Oddělená IoT síť na routeru
  • Tailscale místo VPN serveru
  • Admin rozhraní jen z VPN

Hlídání & zálohy

  • Uptime Kuma + Netdata → Telegram
  • Restic → Cloudflare R2, šifrovaně
  • Každou noc, verzované
  • Watchtower — kromě DNS
