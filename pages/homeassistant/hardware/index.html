Jak začít?

Pro úplné začátečníky

01

Příprava Hardware

  • • Kup Raspberry Pi 5 (min 4GB RAM)
  • • MicroSD 32GB nebo SSD 256GB
  • • Zigbee USB dongle (Sonoff)
02

Instalace

  • • Stáhni Home Assistant OS image
  • • Nahraj na SD/SSD (Balena Etcher)
  • • Boot RPi, čekej 5-10 min
  • • Otevři http://homeassistant.local:8123
03

První konfigurace

  • • Vytvoř účet (lokální, ne cloud!)
  • • Nastav location & timezone
  • • Přidej první integraci
04

Pokročilá konfigurace

  • • SSD boot (rychlejší než SD)
  • • Static IP nastavení
  • • Automatické zálohy
  • • Remote access (WireGuard VPN)
