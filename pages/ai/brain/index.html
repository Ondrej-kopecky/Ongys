Co je Brain System?

Problem: AI asistenti zapomínají kontext mezi sessions. Každý nový rozhovor začínáte od nuly.

Řešení: Brain System je persistentní paměť pro Claude Code. Strukturované soubory, které si agent čte a zapisuje sám.

Výsledek: Žádné opakování, žádné ztracené kontexty. Agent ví co dělal minule, co má dělat teď a co přijde dál.

Workflow

Jak to funguje v praxi

Session Start

  1. EJS šablony vygenerují základní kontext
  2. brain-first-answer zkontroluje git status
  3. brain-status.sh zobrazí přehled
  4. Skills se načtou on-demand

Task Lifecycle

OPEN → PLAN → PROCESS → TEST → REVIEW → DONE

Agent automaticky přechází mezi stavy bez permission.

Session End

  1. /brain-finish
  2. Review aktivních tasků
  3. Changelog entry
  4. NEXT_SESSION_TODO update
  5. Brain vault sync

NEXT_SESSION_TODO

Most mezi sezeními

Proč je to klíčové?

Je pátek večer, pracujete na složitém featureu. Zítra ráno potřebujete vědět: kde jste skončili, co je další krok, jaká je priorita. NEXT_SESSION_TODO je explicitní handoff z jednoho dne do druhého.

# Next Session TODO
**Date:** 2026-01-29
## Continue Work
- [ ] **Task 0018:** Redmine Integration [PROCESS]
- Next: Test journal updates
- Priority: HIGH
## Notes for Next Session
- Watch out for 401 errors

Žádné hádání. Žádné ztrácení času. Prostě pokračujete tam, kde jste skončili.

Kde Brain System pomáhá

Reálné příklady z praxe

01

Web Development

Tento web vznikl kompletně s Claude Code. Brain si pamatuje design systém, strukturu stránek, a kde jsme minule skončili. Nová session = pokračování, ne start od nuly.

02

Home Assistant

Konfigurace HA, automatizace, Grafana dashboardy — Brain zná celou infrastrukturu. Agent ví jaké senzory mám, jaké entity existují a jak spolu souvisí.

03

Pracovní projekty

Frontend, backend, microservices — každý projekt má svůj Brain s architekturou, konvencemi a rozhodnutími. Přepnu projekt a agent okamžitě ví co je za kód.

04

Multi-Agent Orchestrace

Více agentů pracuje paralelně — jeden researchuje, druhý kóduje, třetí testuje. Brain zajišťuje synchronizaci kontextu mezi nimi.

Brain v akci

Reálný příklad: vývoj tohoto webu

Jak Brain pomáhá při vývoji ongy.cz

Tento web vzniká po večerech v krátkých sessions. Bez Brain System bych musel pokaždé vysvětlovat: jaký je tech stack, kde jsou soubory, jaký je design systém, co jsem dělal minule. S Brainem to prostě funguje.

Bez

Bez Brain System

"Mám web ongy.cz, je to statický web, vanilla JS, žádný framework, barvy jsou teal a amber, fonty Montserrat a Inter, obrázky na Cloudinary, minule jsem dělal sekci Deskovky..."

~5 minut kontextu na začátku každé session

S

S Brain System

"Načti si brain."

Agent si přečte NEXT_SESSION_TODO, ví co je za projekt, zná design systém, vidí aktivní úkoly a rovnou se ptá na čem chci pokračovat.

~10 sekund a jedeme

Konkrétní session: 8. března 2026

Řekl jsem "načti si brain" a během jedné session jsme:

  • Přidali 4 blogposty o historii webu
  • Aktualizovali popis na hlavní stránce
  • Provedli bezpečnostní audit celého webu
  • Přidali CSP, Referrer Policy a Permissions Policy do 16 souborů
  • Vylepšili tuto stránku o diagram a příklady

Agent celou dobu věděl: jaký je design systém, kde jsou soubory, jaké jsou pravidla (žádné emoji, žádné frameworky, čeština). Nemusel jsem nic opakovat.

Klíčové principy

K

Kontinuita

Externí paměť pro dlouhodobé projekty. Agent si pamatuje rozhodnutí i mezi sezeními.

E

Efektivita

On-demand loading, 85% úspora tokenů. Žádné plýtvání kontextem.

A

Autonomie

Agent píše do paměti sám bez ptaní. Žádné "Mohu zapsat do changelog?"

S

Struktura

Všechno má své místo. Tasks, decisions, context - každý typ informace má vlastní složku.
